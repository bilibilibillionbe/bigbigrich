币安合约自动交易机器人 —— 实盘部署教程
==================================================

【第 1 步】安装 Python
--------------------------------------------------
1. 打开 https://www.python.org/downloads/ ，点 "Download Python" 下载。
2. 双击安装。安装界面最下面的 "Add python.exe to PATH" 一定要勾选，
   然后点 "Install Now"。


【第 2 步】下载程序
--------------------------------------------------
1. 浏览器先登录你的 GitHub 账号，再打开下面这个链接下载 ZIP：
   https://github.com/bilibilibillionbe/bigbigrich/archive/refs/heads/claude/nifty-franklin-3czzen.zip
2. 右键压缩包 → "全部解压缩"，解压到一个好找的地方，例如 D:\bot


【第 3 步】安装依赖
--------------------------------------------------
双击文件夹里的 setup.bat，等黑色窗口显示 Done，按任意键关闭。
完成后文件夹里会多出一个 config.json 文件。


【第 4 步】创建币安 API Key
--------------------------------------------------
1. 登录币安官网 → 头像 → "API 管理" → "创建 API"，选 "系统生成"。
2. 权限设置：
   - 勾选 "允许合约交易"（Enable Futures）
   - 不要勾选 "允许提现"
   - 建议设置 IP 白名单，填你电脑的公网 IP（百度搜 "IP" 即可查到）
3. 复制并保存 API Key 和 Secret Key（Secret 只显示一次）。


【第 5 步】设置合约账户
--------------------------------------------------
1. 把用来交易的 USDT 从现货账户划转到 "U 本位合约" 账户。
2. 合约交易页面 → 右上角设置 → "持仓模式"，选 "单向持仓"。
3. 如果合约账户里有你手动开的仓位，机器人会跳过那些币种，
   等你平掉后才会交易它们。


【第 6 步】填写配置
--------------------------------------------------
右键 config.json → 打开方式 → 记事本，把开头这几行改成下面这样
（双引号和逗号都要保留）：

  "testnet": false,
  "live_confirm": "YES",
  "api_key": "粘贴你的API Key",
  "api_secret": "粘贴你的Secret Key",

  "mode": "aggressive",
  "capital_cap": 100,

说明：
- mode：aggressive 为激进模式，每笔风险 3%，杠杆上限 10 倍。
- capital_cap：机器人最多使用的本金（USDT）。程序还没在真实环境里下过单，
  建议先用 100，走完一笔正常开仓到平仓后，再改成你想投入的金额。
  改成 0 表示使用合约账户全部余额。
- 其他内容不用动。

按 Ctrl+S 保存。


【第 7 步】启动
--------------------------------------------------
双击 start_bot.bat。窗口里出现下面这些内容，就是启动成功了：

  模式：实盘（真实资金）
  USDT 钱包余额 xxx
  模式 aggressive：每笔风险 3%，杠杆上限 10x，最多 2 仓，交易本金 100 USDT

窗口要一直开着，不要关。


【第 8 步】24 小时运行
--------------------------------------------------
1. 关闭睡眠：设置 → 系统 → 电源 → "接通电源后进入睡眠" 改成 "从不"。
2. 开机自启：右键 start_bot.bat → "创建快捷方式"，
   按 Win+R 输入 shell:startup 回车，把快捷方式拖进打开的文件夹。
3. 如果你平时要开加速器或代理才能上币安，这个工具也要一直开着。
4. 暂停 Windows 自动更新（设置 → Windows 更新 → 暂停更新），
   避免半夜自动重启。设置了开机自启的话，重启后程序会自己恢复。


【第 9 步】第一笔开仓后检查
--------------------------------------------------
4 小时周期可能一两天才开一单，没动静是正常的。
开仓后打开币安 App，检查这三项：
  - 仓位是 "逐仓"
  - "止盈止损" 或 "条件单" 里挂着一张止损单
  - 止损单只有一张
以后每过 4 小时，止损价格可能会往盈利方向移动，这是正常的。


【第 10 步】日常使用
--------------------------------------------------
停止：     关掉黑色窗口（已挂的止损单仍在币安上生效）
重启：     双击 start_bot.bat，会接着管理原来的仓位
看记录：   打开 logs\bot.log
修改设置： 关掉窗口 → 改 config.json → 重新启动
手机通知： 到 sct.ftqq.com 获取 SendKey，填进 config.json 的
           "serverchan_key"，开仓、平仓会推送到微信

几条规矩：
  - 机器人在跑的时候，不要手动改它的仓位和止损单。
  - 不要同时开两个窗口。
  - 回撤超过 60% 时机器人会自动停止开仓，确认后才能恢复。


【常见报错】
--------------------------------------------------
Python not found
  → 重装 Python，勾选 Add python.exe to PATH

config.json 里还没有填 api_key
  → 第 6 步的中文没替换

API Key 无效或权限不足
  → 检查 Key 是否复制完整、是否开了合约权限、IP 白名单是否正确

双向持仓模式
  → 回第 5 步改成单向持仓

资金不足以满足最小下单额
  → capital_cap 太小或合约账户里没钱，调大一点

网络错误（反复出现）
  → 网络连不上币安，检查加速器或代理

出现其他报错，或者开仓后在 App 里没看到止损单：
先在 App 里手动平仓，再把黑色窗口截图发给 Claude。
